# Testing the JobsPic app locally

## Serving the app
- `php artisan serve --port=<port>` (the session typically uses 8011).
- Run `php artisan storage:link` once — without the `public/storage` symlink every `/storage/*` URL (company logos, job ad images, generated posters) returns 404.
- `.env` has `APP_URL=http://localhost` with no port, so `asset()`/route URLs (incl. `og:image`) render without a port. Serve with an env override: `APP_URL=http://localhost:<port> php artisan serve --port=<port>` so generated asset URLs resolve.
- Local dev DB is sqlite (`database/database.sqlite`), seeded with sample jobs (`sample-job-for-<category>-<n>` slugs). Seed data with `php artisan tinker` as needed.

## Feature-specific notes
- **Job posters**: `poster_path` on `job_listings`; generated by `php artisan posters:generate` (only missing posters) or `--force` for all. To null the column without the `JobListingObserver` regenerating the poster on save, use `$job->updateQuietly(['poster_path' => null])` — any normal `update()` touching a watched field (title, deadline, education, company_name, category_id, city_id, bps_scale) regenerates the poster.
- Posters are written to `storage/app/public/job-posters/` — requires the storage symlink and `FILESYSTEM_DISK=public`.
- `og:image`/`asset()` URLs depend on `APP_URL` matching the served origin.

## MCP
- Set `MCP_API_TOKEN` in `.env`; REST at `/api/mcp/*`, JSON-RPC at `POST /api/mcp/rpc` (Bearer token).
- Smoke test: `JOBS_SITE_URL=http://127.0.0.1:<port> MCP_API_TOKEN=<token> npm run mcp:smoke` (from repo root, needs `cd mcp && npm install` first).

- MCP API testing: `POST /api/mcp/<resource>` with `Authorization: Bearer $MCP_API_TOKEN` from .env — useful for creating test entities (posts/jobs) and asserting observer side-effects.
